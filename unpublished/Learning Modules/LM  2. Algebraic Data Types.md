# Learning Module 2: Recursion

**Why this is important:**  Recursion is a foundational principle in both mathematics and computer science.  It is the
second most powerful concept in computer science.  In our course, we will use recursive structures to define and
implent languages.  Further, there is a style of recursion called *tail recursion* that a modern compiler can optimize
to be a loop in machine code.

## Outcomes and Example Assessments

  - 2.1 -- Given reference code, write the corresponding datatype declaration (2 points) 
    : We will give you a recursive function, and you write a dataype that makes it compile and run.
  - 2.2 -- Given a datatype declaration, write a recursive function that consumes the datatype. (2 points) 25%
    : We will give you a datatype, you write a function that processes the data in it.
  - 2.3 -- Given a datatype declaration, write a recursive function that transforms the datatype (3 points) 25%
    : We will give you two datatypes, you write two functions that convert from one to the other and back again.
  - 2.4 -- Given a datatype declaration, write a function that produces it from some other input. (3 points) 25%
    : We will give you a datatype, and some input (like an integer or list) and you generate a dataype with it.  (E.g., BST insert.)
