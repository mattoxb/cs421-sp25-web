# Learning Module 1: Recursion

**Why this is important:**  Recursion is a foundational principle in both mathematics and computer science.  It is the
second most powerful concept in computer science.  In our course, we will use recursive structures to define and
implement languages.  Further, there is a style of recursion called *tail recursion* that a modern compiler can optimize
to be a loop in machine code.

## Outcomes and Example Assessments
  - 1.1 -- Write a recursive function over integers  (2 points)
    : Write a function such as `factorial`.
  - 1.2 -- Write a mapping recursion over lists  (2 points)
    : Write a function to increment all the elements of an integer list.
  - 1.3 -- Write a folding recursion over lists  (2 points)
    : Write a function to multiply together all the elements of an integer list.
  - 1.4 -- Write a tail recursive function  (2 points)
    : Write a function such as `factorial`, but make it tail recursive.
  - 1.5 -- Indicate the advantage of tail recursion over direct style  (2 points)
    : Multiple choice question.

## Mastery Criteria
  - Score 8 of the 10 available points.
