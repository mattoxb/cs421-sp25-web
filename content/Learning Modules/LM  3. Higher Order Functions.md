# Learning Module 3: Higher Order Functions

**Why this is important:**  Higher order functions are one of the major benefits of functional programming.
Being able to assign functions to variables and pass them into other functions allows you to parameterize 
functionality rather than hard code it.  Functions being able to create other functions gives you tremendous
flexibilty in your programming.  These techniques are common now, even in languages that are not considered
to be functional, so it is likely you will see them in industry.

## Outcomes and Example Assessments
  - 3.1 -- Use the following HOFs (1 point each)
    - `map` and `zipWith`
    - `foldr` or `foldl`
    - `all` or `any`
    - `filter`
    - `fix`
    - `curry` or `uncurry`
  - 3.2 -- Implement the above (1 point each)
